# 磁盘写入量面板

一个在本机运行的小网页，用来实时看硬盘的写入速度。

## 怎么用

双击 `start.command`，几秒后浏览器会自动打开面板。

看完直接关掉那个终端窗口即可停止；也可以在里面按 `Control + C`。

## 界面上的数字

| 位置 | 含义 |
| --- | --- |
| 当前写入速度 | 这一秒写进硬盘多少 MB |
| 曲线 | 最近 60 秒的写入速度，鼠标停在上面可看具体数值 |
| 本次会话写入 | 从面板启动到现在累计写了多少 |
| 累计写入 | 这块硬盘从出厂至今写入总量 |
| 本次峰值 | 本次打开以来的最高写入速度 |
| 硬盘温度 | 当前温度，30°C 左右正常 |

## 说明

- 数据来自 `smartctl` 的 `Data Units Written` 计数，1 个单位 = 512,000 字节。
- 每秒采样一次，只读硬盘信息，不会写盘。
- 服务只监听 `127.0.0.1`，数据不出本机。
- 换外接盘：`DEVICE=/dev/disk4 ./start.command`。
- 换端口：`PORT=9000 ./start.command`。
